# Олимп

Веб-приложение для подготовки к олимпиадам по алгебре и информатике.
Включает 24 задачи трёх уровней сложности, проверку ответов,
разборы решений, личный кабинет, историю попыток и рейтинг.
Данные сохраняются в SQLite.

## Запуск

Требуется Python 3.10 или новее. Сторонние библиотеки не нужны.

1. Откройте папку проекта в PyCharm.
2. Выберите интерпретатор Python 3.10+.
3. Запустите файл `app.py`.
4. Откройте в браузере http://127.0.0.1:8000.
5. Зарегистрируйтесь или войдите в аккаунт.

Также приложение можно запустить из терминала в папке проекта:

```sh
python app.py
```

База данных создаётся автоматически при первом запуске.
